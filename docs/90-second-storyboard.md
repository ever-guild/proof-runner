# ProofRunner: 90-Second Storyboard

## Scene 1: The Problem (0:00 - 0:15)
- **Visuals**: Dark, chaotic screen showing scattered GitHub pull requests, endless CI logs, and confused chat messages ("Did the agent break this?", "Is this safe to merge?").
- **Audio**: Fast-paced electronic ticking. 
- **Voiceover/Text**: AI agents are writing code at lightspeed. But who is verifying it? Standard CI wasn't built to trust autonomous agents. 

## Scene 2: The Solution (0:15 - 0:35)
- **Visuals**: Chaos clears. A sleek, dark glassmorphism interface appears—the ProofRunner Landing Page. A lightning strike gradient illuminates the background.
- **Audio**: A deep, satisfying bass drop.
- **Voiceover/Text**: Enter ProofRunner. Independent, immutable verification for agent-built software.

## Scene 3: The Action (0:35 - 0:60)
- **Visuals**: 
  - Zoom into the "Verify Repository" form.
  - A user (or an agent via A2MCP) pastes a GitHub URL and selects a specific Commit SHA.
  - Clicks "Inspect repository".
  - The screen transitions to a secure, isolated sandbox terminal. Logs stream rapidly in a retro green/violet font.
- **Audio**: Smooth, rhythmic typing sounds and low-hum server noise.
- **Voiceover/Text**: Pinned verification skills. Immutable commits. Non-root execution. ProofRunner installs, builds, and tests the exact commit in a frozen sandbox.

## Scene 4: The Proof (0:60 - 0:80)
- **Visuals**: The terminal clears, replaced by a massive, glowing `PASS` receipt. 
  - The camera pans over cryptographic hashes, duration metrics, and the A2MCP seal.
  - Shows the receipt being shared on X (Twitter) using the stunning Open Graph layout.
- **Audio**: A bright, satisfying "chime" sound of approval.
- **Voiceover/Text**: Not just a log—a cryptographic receipt. Portable, public, and verifiable by anyone.

## Scene 5: Outro (0:80 - 0:90)
- **Visuals**: ProofRunner logo centers on screen with the tagline: "Run it. Prove it."
  - Links to GitHub and docs fade in below.
- **Audio**: Fade out to a low, resonant synth note.
- **Voiceover/Text**: ProofRunner. Agent-built software, independently verified.
